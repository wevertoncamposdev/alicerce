# Skill: Add Feature

## Objetivo

Implementar feature com impacto mínimo e segurança.

## Passos

1. Entender escopo e mapear arquivos-alvo.
2. Implementar apenas no escopo.
3. Preservar contratos públicos.
4. Criar/ajustar testes focados.
5. Validar lint/build/test.

## Saída esperada

- Resumo curto da implementação.
- Lista de arquivos alterados.
- Riscos/impactos.
- Passos de validação local.

## Continuidade

- Perguntar se quero códigos de exemplo.
- Depois da confirmação fornecer somente os códigos.
