# Skill: Write Tests

## Objetivo

Cobrir comportamento crítico alterado com testes claros.

## Regras

- Testar comportamento, não implementação interna.
- Cobrir caminho feliz + ao menos 1 caminho de erro.
- Evitar flakiness.

## Saída esperada

- Casos de teste adicionados.
- Limitações de cobertura.
- Comando para executar apenas o escopo afetado.
