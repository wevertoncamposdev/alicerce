# Skill: Bugfix

## Objetivo

Corrigir causa raiz com mínimo efeito colateral.

## Passos

1. Reproduzir mentalmente (ou via teste/log).
2. Identificar causa raiz (não só sintoma).
3. Aplicar correção mínima.
4. Adicionar teste de regressão.
5. Descrever cenário "antes/depois".

## Saída esperada

- Causa raiz.
- Correção aplicada.
- Teste de regressão.
- Risco residual.
